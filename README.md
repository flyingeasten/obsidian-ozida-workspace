# Ozida Workspace

Ozida Workspace is a personal AI workspace and dashboard for Obsidian.

## Vision

Ozida Workspace aims to become a personal operating workspace inside Obsidian.

Planned modules:

- Three-column dashboard UI
- Email to Markdown
- Airtable sync
- AI assistant
- Local Python script integrations
- Automation workflows

## Current Stage

v0.1:
- Obsidian plugin setup
- Classic three-column dashboard UI
- Navigation sidebar
- Workspace cards
- AI copilot panel
